# Submission Guidelines

These guidelines help ensure that all templates in GooDocs are high-quality, consistent, and useful to others.

---

## 📌 What Makes a Good Template

A strong template should:

- Be reusable for multiple people or scenarios
- Have a clear purpose (resume, newsletter, planner, etc.)
- Be visually organized and readable
- Use consistent formatting (headings, spacing, alignment)
- Avoid unnecessary clutter

---

## 🔗 Google Doc Requirements

Your template must include:

- A view link:
  - Must be set to "Anyone with the link can view"
- A copy link:
  - Format:
    https://docs.google.com/document/d/FILE_ID/copy

Both links must work correctly before submitting.

---

## 🖼 Preview Image Requirements

Each template must include a preview image.

Guidelines:

- Format: .png
- Recommended width: ~1200px
- Should clearly show:
  - layout
  - structure
  - key sections

File naming:
- Use lowercase with dashes
- Match the template name

Examples:
resume-modern.png
newsletter-autumn.png
success-plan.png

---

## 🏷 Naming Conventions

### Template Titles

- Use clear, descriptive names
- Avoid generic titles like:
  - Template 1
  - Document

Good examples:
- Minimal Resume
- Skincare Newsletter
- Group Project Evaluation

---

### Image File Names

- lowercase
- hyphen-separated
- no spaces

Example:
group-project-evaluation.png

---

## 🗂 Categories

Choose a category that best fits your template.

Common categories include:

- resume
- newsletter
- planner
- invoice
- notes
- business
- education
- personal
- creative

If unsure, use:
uncategorized

---

## 🧼 Content Rules

Templates must NOT include:

- Personal or identifying information
- Placeholder content that is offensive or inappropriate
- Copyrighted material you don’t have permission to share

---

## 🔁 Consistency Matters

Before submitting, double-check:

- Your JSON entry matches the format
- Your preview image path is correct
- Your title and image name align
- Your links work

---

## 🚫 Common Reasons Submissions Are Rejected

- Broken Google Doc links
- Missing preview image
- Invalid JSON formatting
- Duplicate templates
- Extremely low-effort submissions

---

## 💡 Tips for Better Contributions

- Think: “Would someone actually use this?”
- Keep designs clean and flexible
- Look at existing templates for inspiration
- Start simple—quality matters more than complexity

---

## 🤝 Final Note

GooDocs is built to be a useful, growing library of templates.

Clear, consistent contributions make it better for everyone.

Thanks for contributing 🚀
